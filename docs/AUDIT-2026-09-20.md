## SECURITY POSTURE (Electron desktop app)

- ✅ contextIsolation ON by default (Electron 40), preload uses `contextBridge` (no nodeIntegration)
- ✅ CSP present in index.html (default-src 'self'; frame-src localhost only)
- ✅ No secrets in app code — deploy scripts contain only placeholders (`nama-anda`, `PasswordSelamat...`)
- ✅ **FIXED tonight**: `open-url` IPC handler now validates protocol (http/https only) — previously `shell.openExternal(url)` accepted ANY scheme (file://, custom protocol hijacks)
- ⚠️ `webviewTag: true` — required for the live preview feature; mitigated by CSP frame-src localhost restriction. Acceptable for a local dev tool.
- ⚠️ `runCommand` uses `shell: true` — commands are fixed (`php`, `composer`, `artisan`) with generated args; low risk for local desktop, but avoid interpolating user strings into command args in future.
