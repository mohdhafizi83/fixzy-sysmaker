Gemini question:
Kita hanya ada 2 jam untuk menyelesaikan keseluruhan proses ini. Bantu saya membina aplikasi web menggunakan AppGini. Kita akan membina sistem ________. Strategi saya ialah dengan import database secara terus ke AppGini. Saya minta anda untuk design database bersama fake data (tidak kurang dari 10 data bagi table utama). Design selengkap yang mungkin dengan features yang sesuai. Saya bercadang menggunakan MySQL sebagai database. Jangan gunakan fields dengan data type yang tidak di support oleh AppGini seperti ENUM. Pastikan query tidak mempunyai error dan warning seperti MySQL said:Specified key was too long; max key length is 1000 bytes. Terangkan keperluan setiap table dan fields yang dijana untuk memudahkan pemahaman saya.

Berdasarkan design database, bantu saya untuk membuat report-report yang boleh dilakukan dari data yang ada dalam bentuk chart menggunakan chart.js. Buatkan chart-chart itu didalam satu halaman sahaja. pelbagaikan jenis chart contohnya pie chart, bar chart, dan sebagainya yang sesuai.

saya ingin memasang Calendar pada aplikasi sistem _______. User klik tarikh pada Calendar untuk memasukkan data XXXXXX pada tarikh berkenaan.

RULES:
1. Makesure nama database tanpa _ , -, hanya pure abjad.
2. Jangan buang masa setting, terus generate selepas berjaya masuk ke AppGini.
3. Jika error selepas generate, delete semua folder, AppGini file, dan close AppGini. Mulakan semula bermula import database.
4. Jika tambah field di AppGini dan ada error di generated app, pergi ke Admin Area -> utilities -> view/rebuild fields.
5. Jika ada error No direct access allowed!, maka makesure  lib.php diatas sekali

	include_once(__DIR__ . '/lib.php');
	// Sertakan header dan fail sambungan pangkalan data AppGini
	include_once(__DIR__ . '/header.php');
	
6. Untuk buat public form -------- Generated app -> Admin Area -> Groups-> View Groups -> anonymous
7. Hide Quick search at HOME and multiple layout button in Detail View
//Add them in hooks/footer-extras.php

    <!-- hide Homepage search in Home Page -->
    <script>
        AppGini.disableHomePageSearch = true;
    </script>

    <!-- hide multiple layout button in DV -->
    <script>
        $j(function() {
            $j('.detail_view-layout').remove();
        });
    </script>
8. Untuk membuat calculated field 
// sumbangan ialah table lain. 
SELECT COALESCE(SUM(jumlah), 0.00) FROM sumbangan WHERE id_program = '%ID%'
9. Untuk custom menu, gunakan hooks/links-navmenu.php (top menu) dan hooks/links-home.php
10. Tidak boleh tambah chart, custom info lain di home. Jika nak guna custom home create hooks/home-custom.php
11. submit form, dan perlu dilakukan sesuatu sebelum atau selepas submit (contoh table kelulusan), gunakan hooks/{table}.php
