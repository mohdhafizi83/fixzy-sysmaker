Selamat Datang ke Projek Baharu Anda!

Projek anda masih kosong. Berikut adalah beberapa cara untuk anda bermula:

1. Bina Secara Manual

Gunakan butang New Table dan New Field di menu sisi untuk membina struktur pangkalan data anda dari awal.

2. Guna Bantuan AI (Akan Datang)

Huraikan keperluan aplikasi anda dalam bahasa biasa, dan biarkan AI menjana skema pangkalan data yang lengkap untuk anda.

3. Import Fail .sql

Jika anda sudah mempunyai skema dalam fail .sql, anda boleh mengimportnya secara terus untuk menjana semua jadual dan medan secara automatik.
